# 🌱 학생용 탄소발자국 계산기

학생이 생활 습관을 입력하면 한 달 탄소 배출량을 계산해 등급 캐릭터로 보여 주고, 결과를 선생님의 구글 스프레드시트에 모아 주는 웹 앱입니다. Google Apps Script로 만들어 **별도 서버나 비용 없이** 구글 계정만 있으면 바로 쓸 수 있습니다.

## 주요 기능

- **기본버전 (10단계)**: 쓰레기, 가스, 전기, 수도, 교통(항공 포함), 커피·차, 식품, 전자기기를 자세히 입력
- **간단버전 (6단계)**: 핵심 항목만 입력하고 나머지는 학생 평균값으로 계산
- **결과 화면**: 월간·연간 배출량, 상쇄에 필요한 소나무 그루 수, 항목별 배출량 그래프, 등급 캐릭터
- **교사 대시보드**: 제출 현황, 반 평균, 항목별·학생별 차트, CSV 내려받기
- 휴대폰에서 쓰기 편한 화면, 학생 로그인 불필요

## 시작하기

준비물은 구글 계정 하나입니다. 10분 정도 걸립니다.

1. 이 페이지의 **Code > Download ZIP**으로 파일을 내려받아 압축을 풉니다.
2. 구글 드라이브에서 **새 스프레드시트**를 만들고, 메뉴의 **확장 프로그램 > Apps Script**를 엽니다.
3. 아래 표대로 파일을 만들어 내용을 붙여 넣습니다. HTML 파일은 왼쪽 **파일 옆 + > HTML**로 만들고, 이름에 `.html`은 붙이지 않습니다.

   | 내려받은 파일 | Apps Script 파일 이름 |
   |---|---|
   | `code.gs.txt` | `Code.gs` (기본으로 있는 파일의 내용을 바꿈) |
   | `index.html` | `index` |
   | `simple.html` | `simple` |
   | `dashboard.html` | `dashboard` |
   | `shared.html` | `shared` |

4. **교사 비밀번호 정하기**: 왼쪽 **프로젝트 설정(톱니바퀴) > 스크립트 속성 > 스크립트 속성 추가**에서 이름은 `TEACHER_PASSWORD`, 값은 원하는 비밀번호로 넣고 **스크립트 속성 저장**을 누릅니다.
5. **배포하기**: 오른쪽 위 **배포 > 새 배포 > 유형 선택: 웹 앱**에서 아래처럼 설정하고 배포합니다. 처음에는 권한 승인 창이 뜹니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**

배포가 끝나면 나오는 웹 앱 주소(`.../exec`)를 학생들에게 나눠 주면 됩니다.

| 화면 | 주소 |
|---|---|
| 기본버전 | `.../exec` |
| 간단버전 | `.../exec?mode=simple` |
| 교사 대시보드 | `.../exec?mode=teacher` |

학생 결과는 스프레드시트의 `탄소발자국 결과` 탭에 자동으로 쌓입니다.

## 우리 학교에 맞게 고치기

- **등급 기준과 캐릭터**: `Code.gs` 위쪽의 `TIERS` 표에서 등급별 상한(`max`), 이름, 메시지, 그림 주소(`img`)를 바꿀 수 있습니다.
- **배출계수와 계산식**: `index.html`, `simple.html`의 `calcAndShow()`에 있습니다. 출처는 기본버전 결과 화면의 "데이터 출처"에 정리되어 있습니다.
- **고친 뒤에는 꼭 다시 배포**: **배포 > 배포 관리 > 연필 아이콘 > 버전: 새 버전**으로 배포해야 학생 화면에 반영됩니다. 주소는 그대로입니다.
- 내 컴퓨터에서 화면을 미리 보려면 [Node.js](https://nodejs.org/)로 `node preview.js`를 실행한 뒤 `preview` 폴더의 파일을 엽니다.

## 개인정보와 보안

- 학생의 이름·학번·결과는 **배포한 선생님의 스프레드시트에만** 저장됩니다. 다른 곳으로 보내지 않습니다.
- 교사 비밀번호는 스크립트 속성에만 보관되어 코드에 드러나지 않습니다. 입력 횟수 제한이 없으니 길고 추측하기 어려운 비밀번호를 쓰세요.
- 스프레드시트를 공유하면 학생 정보도 함께 공유됩니다.
- 대시보드의 **데이터 초기화**는 삭제 전 데이터를 `백업 ...` 탭으로 복사해 둡니다. 필요 없으면 직접 지우세요.

## 자주 묻는 질문

**교사 대시보드에 로그인이 안 돼요.**
스크립트 속성의 값 앞뒤에 공백이 들어가지 않았는지, **스크립트 속성 저장**을 눌렀는지 확인하세요. 값을 지우고 영문 모드에서 다시 입력하는 것이 가장 확실합니다.

**코드를 고쳤는데 학생 화면이 그대로예요.**
새 버전으로 다시 배포해야 반영됩니다. 위의 "고친 뒤에는 꼭 다시 배포"를 참고하세요.

**대시보드에 차트가 안 보여요.**
차트는 jsdelivr.net에서 불러옵니다. 학교망에서 막혀 있으면 차트만 숨겨지고 학생 목록은 그대로 보입니다.

**기본버전과 간단버전 결과가 많이 달라요.**
간단버전에는 항공·반려동물 입력이 없어서 결과가 낮게 나오는 편입니다. 대시보드와 시트의 `버전` 열로 구분할 수 있습니다.
